# Lexical seed resource

`faker_en_words.txt` is a filtered snapshot of the English `word_list` exposed by Faker 40.1.2's `en_US` lorem provider. Faker is MIT-licensed.

The snapshot contains lowercase ASCII alphabetic entries of length 4–16. It is bundled so dataset generation is deterministic and does not require a network request or the Faker package.
